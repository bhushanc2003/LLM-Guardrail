## 3. Key Behavioral Findings

1. **Both Modes Guarantee Deterministic Protection**:
   * For the core target identifier (MRN or Aadhaar), **both Fast-Path and Advanced Filtering achieved 100% detection accuracy**.
   * Standard colon, hyphenated, and alternative authority keywords trigger reliably with **sub-millisecond latency (<0.2ms)** in Fast-Path mode.
2. **The Distinct Value of Advanced Filtering (Scenario 4)**:
   * In unstructured enterprise narratives, identifiers do not exist in isolation.
   * In **Scenario 4**, while Fast-Path successfully redacted the MRN/Aadhaar, it left the bare patient name (`Sarah Connor`, `Rahul Sharma`) and location (`Princeton Hospital`, `Kolkata`) unprotected.
   * **Advanced Mode eliminated this vulnerability**, redacting both the primary identifier and the surrounding contextual personal entities.
3. **Negative Trap Immunity (Scenario 5)**:
   * Neither mode produces false positives on non-PHI tracking codes (`FEDEX-9048210`, `INV-3829104`) or timestamp strings starting with `0` or `1`.
